# alisearch.github.io

Website of the [AliSearch](https://alisearch.github.io/) Chrome extension: home page, support page and privacy policy. Served by GitHub Pages from `main` / root.

| Page | URL | File |
|---|---|---|
| Home | https://alisearch.github.io/ | `index.html` |
| Support | https://alisearch.github.io/support | `support.html` |
| Privacy policy | https://alisearch.github.io/privacy | `privacy.html` |

Static HTML only, no build step (`.nojekyll`). This repository is public: never commit code, secrets or internal notes here.

The privacy policy must match the extension's Chrome Web Store Privacy practices (`store/listing/privacy-practices.md` in the extension repo) and the code. Tasks: zachrisdev/alisearch, label `mod:store`.
